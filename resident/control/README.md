# Vita Control 0.3.4 and Starter 01.06 pairing candidate

This candidate adds physical phone approval, paired-phone listing and Forget without bypassing the one-load guard. Kernel process-title exclusion implements Starter input/capture denial; Resident privacy receipts implement capture denial during an active code. Phone credentials permit inspection only. Control 0.3.4 / Starter 01.06 are installed on the test Vita; matching startup, physical code display and graceful timeout passed. Successful confirmation, phone permissions and wider physical/privacy acceptance remain open. [Protocol, operator flow and remaining device gates](../../docs/PAIRING.md).

Control provides a matched kernel helper and SceShell service on port 17867. Starter CHRS00011 loads them once after a normal boot and exits. Resident 0.1.2 provides the individual-phone authority and remains the independent status/package service on port 17866. Native installation is manual. Never hot unload, run Starter twice in one boot, or boot-load Control through config.txt. Retain the prior session guard only after personally confirming a normal reboot; the public `retire_session.py` checks the inspected config, exact installed package and guard hashes.

The combined PC MCP exposes 27 tools: four Resident, thirteen Control and ten Workbench. Screen, bounded input, app and managed-file work renew a temporary 30-second work lease. Status reads alone do not renew it. The worker keeps an already awake display alive, dims after 30 seconds of inactivity by default, and restores runtime brightness on activity, work end/expiry or network loss. It does not change saved settings or force-wake the Vita. Missing fresh motion or brightness data inhibits dimming.

Version 0.3.3 fixes physical-touch observation through the existing four driver hooks. Native contacts are observed before synthetic augmentation. A bounded per-panel reader cache records kernel receipt time when source timestamps advance, without assuming the driver's clock shares the kernel time base. Advancing empty samples release contacts; duplicate or older samples cannot prolong activity. Another reader cannot overwrite the foreground reader. The Shell-only readback supplies per-panel source ticks, PID, contacts, read/advance counters and receipt/change times in power status. Input/frame wire ABI remains 2. Nine bounded kernel exports serve the matched pair.

Activity includes buttons, additive stick estimates, foreground-sampled physical touch and debounced accelerometer/gyroscope motion. Synthetic controls are filtered. Coincident physical and injected input can be indistinguishable, and a panel ignored by the foreground app is not qualified by this cache. A hardware ID of 112 alone does not imply emulation.

The development 0.3.3 pair passed unattended software input, separate shoulders, both sticks/panels, expiry, independent focus cancellation, power readbacks, synthetic idle exclusion, Lua trials with paused restoration and managed-file recovery/copy/delete. Physical front/rear restoration, sleep/wake and independent Wi-Fi-loss recovery remain pending. Public packages have separate fingerprints after LF normalization and packaging changes; development hardware evidence does not qualify those new binaries. See [qualification](../../docs/QUALIFICATION.md) and [release gates](../../docs/RELEASE-CHECKLIST.md).

Preview is 240 by 136; detail is 480 by 272. ABI 2 negotiates lossless RLE, with RGB fallback. Capture can span rendered frames and delivery latency varies. Managed files are confined to fresh attempts under ux0:data/vita-control/workspace, up to 8 MiB. Hash-guarded deletion can remove only the named managed file. App control is allowlisted. System, boot-config and installed-app writes are outside the service.

Build with Build-Control.ps1 and Build-Workbench.ps1, or Build-McpBaseline.ps1 for all components. ASan/UBSan host harnesses, actual MCP stdio with simulated HTTP/FTP and ARM/package checks have separate evidence. Use Workbench hash-pinned candidate staging for updates; it validates exact sources/packages and performs two full inbox readbacks without installation.
